## Spacing Scale

All padding/margin/gutter values in Phase 2 YAML MUST come from this table. Ant Design's default is 8-step; we lock the multiples-of-4 contract explicitly.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-text gap, tag chip internal padding, between status pill icon and text |
| sm | 8px | AgGrid cell padding (already AgGrid default), `contentGutter: [8, 8]` on the 24-swatch color picker grid, between buttons in a toolbar |
| md | 16px | Default card internal padding, between form fields stacked vertically, default `contentGutter: [16, 16]` for top-level pages |
| lg | 24px | Section breaks within a page (e.g., between "Create unit" card and "Existing units" tree), top-of-page margin under the page title |
| xl | 32px | Major layout gap (e.g., between page title and first card) — used sparingly |
| 2xl | 48px | Empty-state vertical padding (centered Result block); CSV wizard step indicator margin-top |
| 3xl | 64px | Page top/bottom padding on long detail pages (`soldier_detail`) |

**Color swatch grid (`my_profile`, D-16):** 4 rows × 6 columns, each swatch 32×32px, gap = 8 (sm), surrounding container padding = 16 (md). A 6×4 grid yields ~256px wide × ~168px tall — fits comfortably in a 480px card.

**Touch target minimum:** 44×44px for the swatch *clickable surface* (32px visual + 6px padding-around hit target via parent Box). Below the 24-swatch density. Buttons inside AgGrid editable cells inherit `size: middle` (32px) — acceptable on desktop-only Phase 2 per CONTEXT D-16 mobile note.

**Exceptions:**
- Status pill (✓/⚠/✗) in CSV preview: cell-renderer string-based, sized by AgGrid's row height (28px default), not by this scale.
- AgGrid internal row/cell spacing is governed by the Alpine theme; do NOT override `headerHeight` or `rowHeight` in Phase 2.

## Typography

The Phase 2 typography scale extends Ant Design defaults; we explicitly pin 4 sizes and 2 weights for predictability.

| Role | Size | Weight | Line Height | Used For |
|------|------|--------|-------------|----------|
| Body | 14px | 400 (regular) | 1.5 | Default text in cells, paragraphs, form field values |
| Label | 14px | 600 (semibold) | 1.5 | Form input labels, AgGrid column headers, Card titles |
| Heading (h2) | 20px | 600 | 1.3 | Card titles when promoted to section headers (`type: Title, level: 2`) |
| Display (h1) | 28px | 600 | 1.2 | Page title only — one per page via `Title level: 1` |

**Hebrew-specific rules:**
- Latin numerals in Hebrew UI (PRD §13.5). Display soldier ID as `12` not `יב`. Dates: `13/05/2026` not `י"ג/אייר/תשפ"ו`.
- DD/MM/YYYY in `he`, YYYY-MM-DD in `en` (Phase 7). Phase 2 hardcodes `DD/MM/YYYY` via AgGrid `valueFormatter` per RESEARCH §"Hebrew RTL Data Tables".
- Hebrew text length is typically ~10% shorter than English equivalents; allocate column widths assuming Hebrew, then add 15% slack for English fallback in Phase 7.
- **Smart-quote display rule (D-12):** the AgGrid cell shows the *canonicalized* `display_name` (no U+2019, no LRM/RLM, no LRE/RLE/PDF/LRO/RLO). Tooltip on hover (cell renderer `tooltipField: '_raw_display_name'`) shows the original pre-strip value for forensic audit. Phase 2 ships canonicalized-only; tooltip-on-hover is a polish ticket flagged for Phase 7.

**Where this is enforced:**
- No global CSS file in Phase 2 — Lowdefy's `config.theme.fontSize: 14` + `config.theme.fontSizeHeading1: 28` + `config.theme.fontSizeHeading2: 20` set in `app/lowdefy.yaml` once.
- AgGrid `headerName` strings are Hebrew literals in YAML (no CSS for headers); column header weight comes from AgGrid Alpine's CSS (already 600 semibold).
- Title blocks use `type: Title, level: 1` (28px) or `level: 2` (20px). No `level: 3+` in Phase 2 — keep the scale narrow.

**Accent reserved for:**
1. Primary submit/confirm buttons (`Button type: primary`) — one per form/page.
2. Active link state in `MenuLink` blocks.
3. Focused-input ring (Ant default behavior — do not override).
4. AgGrid row-selection highlight on click.
5. Hyperlinks in `Paragraph` blocks (e.g., "צור חשבון חדש" link on login page).

**Accent NOT used for:**
- Secondary buttons (`Button type: default`).
- "Add child here" inline tree-table buttons (these are `type: link`, monochrome).
- Hover states on cards (none — Ant default is no hover).
- "Re-invite" checkbox column rows (these use the warning color for the row background, not accent).

**Rationale for sticking with Ant defaults:** Phase 1 shipped with Ant Design's default blue (`#1677FF`) without any theme override. Phase 2 explicitly endorses this as the brand color rather than introducing a new palette mid-build. Phase 7 may revisit for v1.1 brand polish; Phase 2 ships unchanged.

- `db/migrations/0012_org_unit_last_color_index.up.sql` adds the `org_unit.last_color_index SMALLINT DEFAULT -1` column (sentinel `-1` = "no color assigned yet"; first soldier gets index 0).
- Migration test: insert 25 soldiers into one team, assert the 25th wraps back to index 0 (acceptable v1 trade-off per D-15).

## Interaction Patterns

### Inline-edit affordances (AgGrid)

| Surface | Pattern |
|---------|---------|
| `manage_org_units` tree — rename | Single-click on `name` cell → enters edit mode (Lowdefy `editable: true` on that col only); Enter saves, Escape cancels. |
| `manage_soldiers` grid | NOT inline-editable. Click anywhere on row → navigates to `soldier_detail`. Cleaner mental model: list-vs-detail. |
| `team_detail` members grid | Same as manage_soldiers — view-only, click → detail page. |
| `roster_import` preview grid | `defaultColDef.editable: true` (entire grid editable). Double-click to enter editor for that cell. Enter/Tab commits. `onCellValueChanged` re-validates the row. |
| `manage_role_tags` | Read-only entirely. |

### Loading & progress patterns

| Trigger | Component | Hebrew text |
|---------|-----------|-------------|
| Initial page data load | Ant `Spin` (default, wraps each AgGrid) | (no text, just spinner) |
| Form submit in-flight | Button `loading: true` | (button label stays; spinner appears in-button) |
| CSV file upload (parsing) | Ant `Spin` overlay on the upload card | טוען וקורא קובץ... |
| CSV commit progress | Ant `Progress` block, `percent: <n>` | שלחתי {n}/{total} הזמנות |
| Resend rate-limit backoff | `Alert type: warning` shown ABOVE the progress bar | המתנה {sec}ש לפני המשך |

### Keyboard navigation contract (A11Y)

- AgGrid: native keyboard nav already supported — arrow keys move cells, Enter enters edit, Escape cancels. Phase 2 inherits.
- Tab order on `soldier_detail` form: Name → Email → Phone → Status → Seniority → Tags → Notes → Teams → Color → Save. Walks the visual top-to-bottom order in RTL (which IS the natural tab order; Ant respects this with `direction: rtl`).
- Color swatches: tab into the swatch grid → arrow keys move between swatches → Enter selects.
  - **MEDIUM confidence**: Lowdefy Box children may not natively expose arrow-key navigation. Planner verifies; if needed, wrap swatches in `tabIndex: 0` + onKeyDown handlers. Fallback: tab between swatches.

### Validation display rules

- **Field-level:** the input's `validate:` array surfaces a red border + helper text BELOW the field. Ant default behavior; no override needed.
- **Form-level:** if >1 field fails, show a `Message type: error` toast with summary copy from the copywriting contract.
- **CSV row validation:** every cell edit triggers `validate_single_row` request; the row's `status` flips (`ok` → `warn` / `error` → `ok`) and the row background color updates accordingly. Summary count at bottom of grid updates live.

### Error display

- Server errors (5xx, network failures): use `Notification` (not `Message`) so the error stays on screen until the user dismisses it. Include an `error_id` UUID generated server-side so the user can quote it in a support request.
- Validation errors: field-level + form-level toast as above.
- 403 cross-tenant probe: Lowdefy's default 403 page (Phase 1 wires a custom one if needed). NOT Phase 2's concern.
