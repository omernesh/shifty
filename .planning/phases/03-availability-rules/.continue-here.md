## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Low-code GUI authoring for app shells | Lowdefy (silent plugin drops, `_state:` testing trap, missing antd blocks) + Budibase (screen fixtures applied but runtime-inert; bindings only resolve in browser; hover-revealed Builder UI affordances invisible to chrome-devtools MCP) both failed for Shifty. | advisory | NEXTJS-CONVENTIONS §1 makes App Router routes the UI source of truth; pivot ADR records the rationale. |
| Cross-tenant data leak via missing Layer-2 boundary | Direct `db.select()` calls outside the typed `tenantScopedQuery` helper would silently leak rows across tenants. Release-blocking per PRD §8.3. | blocking | W1 Task 6 ships a ts-morph CI gate (`tools/check-tenant-isolation.mjs`) that fails the build on any `db.*` reference outside `src/lib/tenant/`. |
| Postgres role used by app has RLS bypass | During Budibase era, Postgres connections used the superuser role → Layer-5 RLS effectively disabled. Post-pivot, app must connect as `shifty_app` (migration 0013) for Layer-5 to actively gate writes. | blocking | W1 Task 3 wires `withTenantTx(tenantId, fn)` to use a `shifty_app`-owned pool; Task 7 includes a write-probe integration test that asserts cross-tenant INSERT fails with code 42501. |
