The spec asserts each precedence combination produces the documented winner — a regression here would directly leak rule-evaluation correctness into Phase 04's solver.

<interfaces>
DeclareAvailability contract (RESEARCH Recipe 5):
  Payload: { planning_window_id, mode, soldier_id?, range_from?, range_to?, shift_instance_id?, declared? }
  - mode='range_blockout'   → required: planning_window_id, mode, range_from, range_to
  - mode='per_slot_toggle'  → required: planning_window_id, mode, shift_instance_id, declared
  - mode='manager_override' → required: planning_window_id, mode, soldier_id, shift_instance_id, declared
  Returns: { writes, mode, soldier_id }

Source-precedence ON CONFLICT WHERE clauses (RESEARCH Recipe 5):
  range_blockout: WHERE availability.source = 'default' OR availability.source = 'range_blockout'
                  (won't overwrite per_slot or manager_override)
  per_slot:       WHERE availability.source <> 'manager_override'
                  (overwrites range_blockout and default, not manager_override)
  manager_override: no WHERE — always overwrites

Source-precedence READ query (RESEARCH Recipe 6):
  SELECT si.id, si.date, ss.name, COALESCE(av.declared, 'available') AS declared,
         COALESCE(av.source, 'default') AS source
  FROM shift_instance si JOIN shift_slot ss
  LEFT JOIN LATERAL (
    SELECT id, declared, source FROM availability a
    WHERE a.shift_instance_id = si.id AND a.soldier_id = :soldier_id AND a.tenant_id = :tenant_id
    ORDER BY CASE a.source WHEN 'manager_override' THEN 3 WHEN 'per_slot' THEN 2 WHEN 'range_blockout' THEN 1 ELSE 0 END DESC
    LIMIT 1
  ) av ON true
  WHERE si.tenant_id = :tenant_id AND si.planning_window_id = :pw_id
  ORDER BY si.date, ss.display_order, si.headcount_index;

availability schema (0004 + 0014):
  id UUID PK, tenant_id UUID, soldier_id UUID, shift_instance_id UUID, planning_window_id UUID NOT NULL,
  declared TEXT CHECK in (available|unavailable), source TEXT CHECK in (default|range_blockout|per_slot|manager_override),
  created_at, updated_at,
  UNIQUE (soldier_id, shift_instance_id)
